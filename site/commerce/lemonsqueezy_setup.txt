Lemon Squeezy — création des abonnements Flipcards GADA
=======================================================

Option A (recommandée) — API
----------------------------
1) Compte : https://app.lemonsqueezy.com (créer un Store)
2) Settings → API → Create API key
3) Dans .env :
   LEMON_SQUEEZY_API_KEY=...
   LEMON_SQUEEZY_STORE_ID=...   (optionnel)
4) python commerce/setup_lemonsqueezy.py
5) python commerce/build_assets.py
6) python commerce/update_notion_links.py
7) Redeploy host (commerce/host-repo)

Produits attendus (voir aussi lemonsqueezy_products.json)
---------------------------------------------------------
- Flipcards GADA — Abonnement étudiants
  - Variante Mensuel : 6,90 € / mois
  - Variante Annuel  : 59 € / an

Option B — manuel dans le dashboard
-----------------------------------
1) Products → New product (subscription)
2) Name: Flipcards GADA — Abonnement étudiants
3) Variants Mensuel / Annuel aux prix ci-dessus
4) Copie les share/checkout URLs dans commerce/config.json :
   lemonsqueezy.monthly_checkout_url
   lemonsqueezy.yearly_checkout_url
5) python commerce/build_assets.py && update_notion_links.py
