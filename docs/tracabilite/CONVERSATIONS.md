# Index des conversations Cursor — à archiver

Format d’archivage recommandé (à faire par l’utilisateur) :

1. Exporter / sauvegarder chaque conversation (Cursor cloud ou copie locale des transcripts).
2. Ranger dans un dossier hors repo, ex.  
   `G:\Mon Drive\Editions Particulieres\_archives\conversations-cursor\YYYY-MM\`
3. Cocher « archivée » dans la colonne Statut ci-dessous.

Les IDs permettent de retrouver les transcripts locaux sous  
`%USERPROFILE%\.cursor\projects\*\agent-transcripts\<id>\`.

Convention de citation Cursor : `[titre](uuid)` sans `.jsonl`.

## E. Procédure d’archivage batch

```text
1. Créer G:\Mon Drive\Editions Particulieres\_archives\conversations-cursor\2026-08\
2. Pour chaque ID ci-dessus : copier le dossier agent-transcripts\<id>\
   depuis .cursor\projects\<projet>\agent-transcripts\
3. Ajouter un fichier INDEX.txt listant titre + id + date
4. Cocher « archivée » dans ce document
5. Ne pas committer les transcripts dans git (volume + données personnelles)
```

Les conversations listées comme **à archiver** ne doivent plus servir de source de vérité : **`HISTORIQUE.md` fait foi**.
